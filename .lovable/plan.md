# نقل مشروع aziiizah-s-compass إلى هذا المشروع

المستودع عام ويعمل بنفس تقنيات هذا المشروع (TanStack Start + React 19 + Tailwind v4 + shadcn/ui + Supabase)، لذا يمكن نقل الكود كما هو.

## ما سيتم عمله

1. **تنزيل كود المستودع** من الفرع `main` ونسخه فوق ملفات هذا المشروع:
   - الصفحات: الرئيسية، تسجيل الدخول، الخطط، صفحة العلامة العامة `m/:slug`، لوحة التحكم، صفحات المنصة (المستأجرون) وصفحة التطبيق `app/:slug`
   - المكوّنات: `AppShell`، شريط التنقل، `ui-blocks`، ومكتبة `components/ui` كاملة
   - الخطافات والمكتبات: `useAuth`، `useTenantTheme`، `roles`، `tenant`
   - التصميم: `src/styles.css` وتهيئة الجذر `__root.tsx`
2. **تثبيت الحزم الناقصة** الموجودة في `package.json` الخاص بالمستودع وغير موجودة هنا (Supabase، مكوّنات Radix الإضافية، react-hook-form، recharts، sonner، date-fns، إلخ).
3. **تفعيل Lovable Cloud** في هذا المشروع (قاعدة بيانات + تسجيل دخول) وتطبيق ملفات المهاجرة الأربعة الموجودة في `supabase/migrations` لإنشاء الجداول والسياسات — **ببيانات فارغة** كما اخترت. سيتم توليد ملفات `src/integrations/supabase/*` تلقائياً بمفاتيح هذا المشروع بدل مفاتيح المشروع القديم.
4. **حذف صفحة البداية الافتراضية** واستبدالها بصفحة المستودع الرئيسية.
5. **التحقق**: تشغيل المعاينة والتأكد من أن الصفحات تفتح بدون أخطاء، ومن أن التنقل وتسجيل الدخول يعملان.

## ملاحظات تقنية

- ملف `.env` الموجود في المستودع لن يُنقل؛ متغيّرات Supabase هنا تُدار تلقائياً بواسطة Lovable Cloud.
- ملف `src/routeTree.gen.ts` مُولَّد تلقائياً، لن يُنسخ يدوياً بل يُعاد توليده من ملفات المسارات.
- `package-lock.json` القديم سيُترك خارج النقل (المشروع يستخدم bun).
- بخصوص Vercel: الكود هنا قابل للتصدير عبر GitHub والنشر على Vercel، لكن جزء قاعدة البيانات/تسجيل الدخول يبقى مربوطاً بخدمة Lovable Cloud (Supabase) عبر متغيّرات البيئة — ستحتاج ضبطها في Vercel عند النشر.

## بعد النقل

أخبرني بالتعديلات المطلوبة وسأنفّذها على النسخة المنقولة.
